Firefox extension

Sqomoot

See the squadrats your friends have collected right on the Komoot planning map. Add users by UID, toggle their squares with a checkbox, color-code each rider. Your list never leaves your machine.

Download for Firefox sqomoot-firefox.xpi
🗺️

Two levels of detail

Big squares (z14, ~1.5 km) at continent zoom, fine squadratinhos (z17) when you zoom in — just like squadrats.com.

🔒

Stays on your machine

No accounts, no servers. Users, aliases and tile caches live only in your browser's local storage.

⚡

Fast & polite

Tile data is cached for 24 h, requests are throttled, and layers re-appear automatically after Komoot style switches.

Install

  1. Click the green download button above — Firefox shows an “Add Sqomoot?” prompt.
  2. Click Add. The extension appears in the toolbar.
  3. Open a Komoot plan page (komoot.com/plan) — the Squadrats panel appears at the top right.
  4. Find a UID: open squadrats.com, click any profile — the URL reads /u/<UID>.
  5. Click + in the panel, paste the UID, add an optional alias. Done — toggle users with checkboxes.

If no prompt appears: save the file, then in Firefox choose File → Open File… and pick the .xpi.

Signing. Release builds of Firefox only install add-ons signed by Mozilla. If the download is rejected, AMO signing credentials are not yet configured in the build pipeline — set AMO_API_KEY / AMO_API_SECRET repo secrets and re-run the Pages workflow. See the repository README for details.
