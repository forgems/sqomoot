Sqomoot

Firefox extension that overlays the collected Squadrats of selected users on the Komoot planning map. Add users by UID with an alias; toggle each user's squares with a checkbox. All data stays on your machine.

Download for Firefox (.xpi)

Install

  1. Click the download button above (the file is served from this same site, so Firefox shows the install prompt).
  2. Firefox asks: "Add Sqomoot?" → Add.
  3. Open a Komoot plan page (komoot.com/plan) — the Squadrats panel appears top-right. Click + and paste a Squadrats UID.

If no prompt appears: save the file, then in Firefox use File → Open File… and pick the .xpi.

Signing. Release builds of Firefox only install add-ons signed by Mozilla. If the download above is rejected, the build pipeline has not been configured with AMO signing credentials yet — see the repository README (set AMO_API_KEY / AMO_API_SECRET repo secrets and re-run the Pages workflow).
